# 每日一句

「每日一句」是一个 CC GUI 插件，会在状态栏左侧展示随机句子，并可按设定间隔自动更新。

## 功能

- 支持打字机、滚动和渐隐显示效果。
- 可配置接口地址、句子字段和来源字段。
- 支持每天、每小时、每 30 分钟、每 5 分钟、每分钟自动更新，也可设为仅手动更新。
- 默认使用 Hitokoto，失败时尝试备用句子接口。
- 网络请求仅允许访问清单声明的 `v1.hitokoto.cn` 和 `v2.xxapi.cn`。

## 安装

在 CC GUI 的「插件」市场中搜索「每日一句」并安装。也可以在侧边栏打开「插件」→「从本地目录安装」，选择包含 `manifest.json` 的目录。

## 设置

在插件页打开「每日一句」设置，可选择显示动画、填写接口地址及字段映射，并调整自动更新间隔。手动更新可用于立即获取下一句话。

自定义接口的主机必须已在插件清单的网络权限中获批；当前发行版授权 `v1.hitokoto.cn` 与 `v2.xxapi.cn`。
